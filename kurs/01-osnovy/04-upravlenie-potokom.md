# 4. Управление потоком: `if`, `for`, `switch`

> ⏱ **~45 минут** · теория 15 мин · практика 30 мин

Управляющих конструкций в Go всего три, и одна из них — цикл `for` — заменяет собой `while`, `do-while` и `foreach` из других языков. Это хорошая иллюстрация подхода: вместо четырёх способов сделать одно и то же язык даёт один, но с несколькими формами.

## `if`

Скобок вокруг условия нет, фигурные обязательны даже для одной строки:

```go
if n > 5 {
	fmt.Println("много")
} else {
	fmt.Println("мало")
}
```

Круглые скобки не запрещены, но `gofmt` их уберёт:

```
-	if (1 > 0) {
+	if 1 > 0 {
```

Условие обязано быть `bool`. Никаких «непустая строка — истина», как в Python или JavaScript.

Особенность, которой в Go пользуются постоянно, — **инструкция перед условием**:

```go
if n := len(os.Args); n > 5 {
	fmt.Println("много аргументов:", n)
} else {
	fmt.Println("аргументов:", n)
}
```

Переменная `n` видна в обеих ветвях `if`/`else` и **больше нигде**. Область видимости сужена до места, где переменная нужна. Эта форма станет основной при обработке ошибок (статья 13): `if err := doSomething(); err != nil { ... }`.

## `for` — единственный цикл

Классическая форма:

```go
for i := 0; i < 3; i++ {
	fmt.Print(i, " ")
}
```

Форма с одним условием заменяет `while`:

```go
n := 0
for n < 3 {
	n++
}
```

Без условия — бесконечный цикл, выход через `break` или `return`:

```go
for {
	// ...
}
```

Форма `range` перебирает коллекции, выдавая индекс и значение:

```go
sum := 0
for i, v := range []int{10, 20, 30} {
	sum += i * v
}
```

Если индекс не нужен, его отбрасывают через `_`: `for _, v := range items`. Если нужен только индекс — второе значение просто опускают: `for i := range items`.

Начиная с Go 1.22 `range` работает и с целыми числами:

```go
for i := range 3 {
	fmt.Print(i, " ")     // 0 1 2
}
```

Удобная замена `for i := 0; i < 3; i++`, когда счётчик нужен только для повторения.

Есть важная тонкость `range`, о которой стоит знать заранее: **переменная цикла получает копию значения**. Изменение `v` внутри цикла не меняет элемент коллекции — для этого обращаются по индексу. К этому вернёмся в статье 6, когда разберём слайсы.

## `switch`

В Go он заметно мощнее, чем в C-подобных языках. Первое отличие — **не проваливается**: `break` в конце каждой ветви не нужен.

```go
switch day {
case "сб", "вс":
	fmt.Println("выходной")
case "вт":
	fmt.Println("вторник")
	fallthrough
case "ср":
	fmt.Println("провалились в среду")
default:
	fmt.Println("будни")
}
```

```
вторник
провалились в среду
```

В одной ветви можно перечислить несколько значений через запятую. Если провалиться всё-таки нужно — есть явное `fallthrough`. Оно встречается редко, и это правильно: неявное проваливание в C — источник классических багов.

Второе отличие — **`switch` без выражения** работает как цепочка `if/else if`:

```go
switch {
case n < 0:
	return "отрицательное"
case n == 0:
	return "ноль"
case n < 100:
	return "маленькое"
default:
	return "большое"
}
```

Так в Go записывают многоветвевые условия — читается лучше, чем лестница из `else if`. Ветви проверяются сверху вниз, поэтому частные случаи ставят первыми.

Есть и третья форма — `switch` по типу значения, но она требует интерфейсов, поэтому ждёт статьи 12.

## Метки

Из вложенных циклов выходят по метке:

```go
outer:
	for i := range 3 {
		for j := range 3 {
			if i*j > 2 {
				break outer
			}
			fmt.Print(i*j, " ")
		}
	}
```

Без метки `break` вышел бы только из внутреннего цикла. Метка ставится перед циклом и работает и с `break`, и с `continue`.

Формально в Go есть и `goto`, но в реальном коде он практически не встречается — не тратьте на него время.

## Чего в Go нет

Стоит проговорить явно, чтобы не искать:

- **тернарного оператора** `a ? b : c` — вместо него полноценный `if` или `switch`;
- **`while`** — его роль играет `for` с условием;
- **`do-while`** — эмулируется бесконечным `for` с `break` в конце.

Отсутствие тернарного оператора — сознательное решение авторов: вложенные тернарники плохо читаются, а выигрыш в две строки того не стоит.

## Что запомнить

- Условие `if` пишется без круглых скобок и обязано быть `bool`; фигурные скобки обязательны всегда.
- Форма `if x := ...; условие` ограничивает область видимости переменной телом условия — основная идиома при работе с ошибками.
- `for` — единственный цикл: с тремя частями, с одним условием (как `while`), бесконечный и `range`.
- `range` по числу (`for i := range 3`) доступен с Go 1.22.
- Переменная цикла в `range` — копия значения, а не сам элемент.
- `switch` не проваливается по умолчанию; для провала есть явный `fallthrough`.
- `switch` без выражения заменяет лестницу `else if`.
- Из вложенных циклов выходят по метке; тернарного оператора и `while` в языке нет.

## Практика

**1. Область видимости.** Напишите функцию, где переменная объявлена в `if` и используется в обеих ветвях. Затем попробуйте обратиться к ней после `if` и объясните ошибку. Готово, когда понимаете, где заканчивается видимость.

**2. Четыре формы `for`.** Напечатайте числа от 1 до 5 четырьмя способами: классическим циклом, циклом с условием, бесконечным с `break` и через `range` по числу. Готово, когда все четыре дают одинаковый вывод.

**3. `switch` вместо лестницы.** Напишите функцию, переводящую оценку (0–100) в буквенную (A–F), используя `switch` без выражения. Готово, когда в коде нет ни одного `else if`.

**4. Проваливание.** Напишите `switch`, где одна ветвь намеренно проваливается в следующую. Затем уберите `fallthrough` и сравните вывод. Готово, когда понимаете, чем поведение Go отличается от C.

**5. Метки.** Найдите первую пару чисел из диапазона 1–20, произведение которых больше 150, и полностью прекратите перебор. Сначала попробуйте без метки. Готово, когда программа печатает ровно одну пару.
