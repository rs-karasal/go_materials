# 8. Строки, байты и руны

> ⏱ **~45 минут** · теория 20 мин · практика 25 мин

Строка в Go — это последовательность **байтов**, а не символов. Пока вы работаете с латиницей, разницы не видно. Стоит появиться кириллице или эмодзи — и `len` начинает врать, а срез разрезает букву пополам. Разберёмся, как устроены строки и что такое руна.

## Строка — неизменяемая последовательность байтов

```go
s := "привет"
fmt.Println(len(s))     // 12, а не 6
```

`len` возвращает число **байтов**. В UTF-8 латинская буква занимает один байт, кириллическая — два, иероглиф — три, эмодзи — четыре. Шесть русских букв дали двенадцать байтов.

Обращение по индексу тоже даёт байт:

```go
fmt.Println(s[0])                  // 208
fmt.Printf("%T\n", s[0])           // uint8
```

Число 208 — первый байт двухбайтовой буквы «п», сам по себе бессмысленный.

Строки **неизменяемы**:

```go
// ❌ не компилируется
s := "abc"
s[0] = 98
```

```
im/main.go:5:2: cannot assign to s[0] (neither addressable nor a map index expression)
```

Благодаря этому строку можно передавать без копирования и безопасно использовать из нескольких горутин. Изменить строку — значит создать новую.

## Руна

Руна (`rune`) — это кодовая точка Unicode, псевдоним `int32`. Один символ, независимо от того, сколько байтов он занимает.

Литералы рун пишут в одинарных кавычках: `'п'`, `'A'`, `'😀'`. Строки — только в двойных.

Для подсчёта символов есть отдельная функция:

```go
utf8.RuneCountInString(s)     // 6
```

Правило простое: **`len` — байты, `RuneCountInString` — символы**. Если вы считаете длину имени пользователя для проверки формы, вам почти всегда нужна вторая.

## Два способа перебора

Разница принципиальная. Цикл по индексу идёт **по байтам**:

```go
for i := 0; i < len(s); i++ {
	fmt.Print(s[i], " ")
}
```

```
208 191 209 128 208 184 208 178 208 181 209 130
```

Цикл `range` — **по рунам**:

```go
for i, r := range s {
	fmt.Printf("%d:%c ", i, r)
}
```

```
0:п 2:р 4:и 6:в 8:е 10:т
```

Обратите внимание: `range` по строке выдаёт не порядковый номер символа, а **байтовое смещение** — 0, 2, 4… Он декодирует UTF-8 на лету и отдаёт готовые руны.

Практический вывод: **перебирайте строки через `range`**, если только вам не нужны именно байты.

## Преобразования

```go
runes := []rune(s)      // 6 элементов
bytes := []byte(s)      // 12 элементов
```

`[]rune` нужен, когда требуется индексный доступ к символам: развернуть строку, взять третий символ, посчитать позицию. Помните, что преобразование **выделяет память и копирует** — в горячем цикле это заметно.

`[]byte` нужен для работы с данными: запись в файл, отправка по сети, хеширование. Стандартная библиотека часто работает именно с байтами.

## Срезы

Срез строки режет по байтам — со всеми последствиями:

```go
s[:4]          // "пр" — повезло, попали на границу
```

Промахнётесь мимо границы символа — получите битые данные (в отличие от Rust, паники здесь не будет). Правильный способ резать по символам:

```go
string(runes[:2])     // "пр"
```

## Сборка строк

Конкатенация через `+` создаёт **новую строку** на каждой операции — в цикле это квадратичная сложность. Для сборки есть `strings.Builder`:

```go
var b strings.Builder
for i := range 3 {
	fmt.Fprintf(&b, "%d-", i)
}
fmt.Println(b.String())     // 0-1-2-
```

`Builder` накапливает байты в растущем буфере и отдаёт строку один раз. Правило: **больше двух-трёх склеек в цикле — берите `Builder`**.

Нулевое значение `Builder` готово к работе — инициализировать его не нужно, что снова иллюстрирует принцип из статьи 3.

## Пакет `strings`

Пригодится с первого дня:

- **`ToUpper`, `ToLower`** — смена регистра.
- **`Contains`, `HasPrefix`, `HasSuffix`** — поиск подстроки.
- **`Split`, `Fields`** — разбиение по разделителю и по пробелам.
- **`Join`** — склейка слайса строк.
- **`TrimSpace`, `Trim`** — обрезка.
- **`ReplaceAll`** — замена.
- **`EqualFold`** — сравнение без учёта регистра.

Строки сравниваются обычными операторами: `==` работает побайтно, `<` даёт лексикографический порядок. Для сравнения без регистра — `strings.EqualFold`, а не приведение обеих строк к нижнему регистру: оно корректнее работает с Unicode и не выделяет память.

## Что запомнить

- Строка — неизменяемая последовательность байтов в UTF-8.
- `len` считает байты; символы считает `utf8.RuneCountInString`.
- Обращение по индексу даёт байт (`uint8`), а не символ.
- Руна — кодовая точка Unicode, псевдоним `int32`; литералы в одинарных кавычках.
- Цикл по индексу идёт по байтам, `range` — по рунам и выдаёт байтовое смещение.
- `[]rune` даёт доступ к символам по индексу, `[]byte` — к данным; оба преобразования копируют.
- Срез строки режет по байтам и может разрубить символ.
- Для сборки строк в цикле используйте `strings.Builder`, а не `+`.

## Практика

**1. Байты против символов.** Для строки из русских, латинских букв и эмодзи выведите длину в байтах и в рунах. Готово, когда можете предсказать оба числа до запуска.

**2. Два перебора.** Переберите одну строку с кириллицей двумя способами — по индексу и через `range` — и объясните разницу в выводе. Готово, когда понимаете, что означают индексы в `range`.

**3. Разворот строки.** Напишите функцию, разворачивающую строку задом наперёд, корректно работающую с кириллицей. Проверьте на `"привет"` и на строке с эмодзи. Готово, когда символы не рассыпались.

**4. Builder против конкатенации.** Соберите строку из 100 000 фрагментов двумя способами и замерьте время. Готово, когда есть два числа и объяснение разницы в порядок величин.

**5. Разбор текста.** Напишите функцию, которая принимает предложение и возвращает: количество слов, самое длинное слово (по символам, не по байтам) и предложение в верхнем регистре. Готово, когда все три ответа верны для текста с кириллицей.
