# 7. Карты (`map`)

> ⏱ **~45 минут** · теория 15 мин · практика 30 мин

Карта — хеш-таблица, встроенная в язык. Пользоваться ей просто, но есть три вещи, которые новички узнают на собственных ошибках: отсутствующий ключ не вызывает ошибку, порядок обхода случаен, а запись в `nil`-карту роняет программу. Разберём всё сразу.

## Создание и базовые операции

```go
ages := map[string]int{"Алия": 30, "Ерлан": 25}
ages["Данияр"] = 41

fmt.Println(len(ages), ages["Алия"])     // 3 30
```

Тип записывается как `map[КлючТип]ЗначениеТип`. Пустую карту создают литералом `map[string]int{}` или через `make(map[string]int)` — разницы почти нет, но `make` позволяет намекнуть на размер: `make(map[string]int, 100)`.

Удаление — встроенная функция `delete`:

```go
delete(ages, "Ерлан")
```

Удалять несуществующий ключ безопасно, проверять не нужно.

## Отсутствующий ключ

Первая ловушка. Обращение по ключу, которого нет, **не является ошибкой**:

```go
missing := ages["нет такого"]
fmt.Println(missing)      // 0
```

Возвращается нулевое значение типа: `0` для чисел, `""` для строк, `nil` для указателей. Отличить «ключа нет» от «ключ есть, но значение нулевое» так невозможно.

Для этого — форма с двумя значениями:

```go
v, ok := ages["Ерлан"]
fmt.Println(v, ok)        // 25 true

v, ok = ages["Нет"]
fmt.Println(v, ok)        // 0 false
```

Идиома называется «comma ok» и встречается в Go повсеместно — она же работает с каналами и приведением типов. Обычно её пишут прямо в `if`:

```go
if v, ok := ages["Алия"]; ok {
	fmt.Println("нашли:", v)
}
```

Побочная выгода от нулевых значений — счётчики пишутся в одну строку:

```go
counts := map[string]int{}
for _, w := range strings.Fields("мама мыла раму мама") {
	counts[w]++
}
```

Первое обращение к новому слову даёт 0, увеличение записывает 1. Проверка на существование не нужна.

## Порядок обхода случаен

Вторая ловушка:

```go
for k, v := range ages {
	fmt.Println(k, v)
}
```

Порядок будет **разным при каждом запуске**. Это не побочный эффект реализации, а намеренное поведение: рантайм специально рандомизирует старт обхода, чтобы никто не написал код, полагающийся на порядок.

Нужен предсказуемый вывод — сортируйте ключи явно:

```go
keys := make([]string, 0, len(ages))
for k := range ages {
	keys = append(keys, k)
}
sort.Strings(keys)
```

С Go 1.23 это делается короче через пакеты `maps` и `slices`:

```go
sorted := slices.Sorted(maps.Keys(ages))
```

## `nil`-карта

Третья ловушка, и самая болезненная. Нулевое значение карты — `nil`, и **читать** из неё можно:

```go
var m map[string]int
fmt.Println(m["x"], len(m))     // 0 0
```

А вот запись роняет программу:

```go
var m map[string]int
m["x"] = 1
```

```
panic: assignment to entry in nil map
```

Здесь Go отступает от собственного принципа осмысленного нулевого значения — в отличие от слайса, куда `append` в `nil` работает.

Практический вывод: **карту нужно инициализировать**. Особенно внимательно с полями структур: объявили структуру с полем-картой, создали её через `Item{}` — поле осталось `nil`, и первая же запись обрушит программу. Такие карты создают в конструкторе.

## Требования к ключу

Ключом может быть любой **сравнимый** тип: числа, строки, `bool`, указатели, интерфейсы, а также массивы и структуры из сравнимых типов.

```go
type Point struct{ X, Y int }
byPoint := map[Point]string{{1, 2}: "первая"}
```

Структура как ключ — рабочий приём для составных идентификаторов.

Несравнимые типы — слайсы, карты, функции — ключами быть не могут:

```go
m := map[[]int]string{}
```

```
sk/main.go:4:11: invalid map key type []int
```

Причина в том, что сравнение слайсов не определено: непонятно, сравнивать по адресу или поэлементно. Если ключ должен быть составным и переменной длины, его превращают в строку или в массив фиксированного размера.

## Карта как множество

Отдельного типа множества в Go нет. Его делают картой с пустым значением:

```go
set := map[string]struct{}{}
set["a"] = struct{}{}

_, exists := set["a"]
```

`struct{}` — пустая структура, занимающая **ноль байт**. Можно использовать `map[string]bool` — читается проще, но тратит по байту на элемент. На больших объёмах разница заметна, поэтому в библиотечном коде принят первый вариант.

## Карта — ссылочный тип

Как и слайс, карта передаётся в функцию «по ссылке» на внутреннюю структуру: изменения внутри функции видны снаружи. Копии карты не происходит — для этого нужно копировать вручную (или через `maps.Clone`).

И ещё одно ограничение: **нельзя взять адрес элемента карты**. Запись вида `&m["ключ"]` не компилируется, а изменить поле структуры прямо в карте (`m["k"].Field = 1`) не получится. Обходят это, храня в карте указатели или перезаписывая значение целиком.

## Что запомнить

- Карта создаётся литералом или через `make`; удаление — `delete`, размер — `len`.
- Отсутствующий ключ возвращает нулевое значение, а не ошибку.
- Форма «comma ok» (`v, ok := m[k]`) отличает отсутствие ключа от нулевого значения.
- Счётчики пишутся без проверки существования: `counts[w]++`.
- Порядок обхода намеренно случаен; для стабильного вывода ключи сортируют.
- Чтение из `nil`-карты безопасно, запись вызывает панику — карту всегда инициализируют.
- Ключ должен быть сравнимым: слайсы, карты и функции ключами быть не могут.
- Множество делают через `map[T]struct{}` — пустая структура не занимает памяти.
- Карта передаётся по ссылке; взять адрес элемента нельзя.

## Практика

**1. Comma ok.** Заведите карту оценок. Напишите функцию, которая по имени возвращает оценку и признак наличия, и корректно печатает «нет данных» для отсутствующих. Готово, когда студент с оценкой 0 и отсутствующий студент различаются.

**2. Частотный словарь.** Посчитайте частоту слов в предложении и выведите результат, отсортированный по убыванию частоты, а при равенстве — по алфавиту. Готово, когда порядок вывода одинаков при десяти запусках.

**3. Паника на nil.** Опишите структуру с полем-картой, создайте её через литерал без инициализации поля и попробуйте записать значение. Получите панику. Затем добавьте конструктор. Готово, когда обе версии воспроизводятся осознанно.

**4. Составной ключ.** Постройте карту, где ключ — структура из двух полей (например, город и год), а значение — число. Заполните и прочитайте. Затем попробуйте использовать ключом слайс и разберите ошибку. Готово, когда понимаете требование сравнимости.

**5. Множество и пересечение.** Реализуйте на `map[string]struct{}` две операции: объединение и пересечение двух множеств. Готово, когда обе функции возвращают новое множество, не изменяя исходные.
