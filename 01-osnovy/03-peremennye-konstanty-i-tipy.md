# 3. Переменные, константы, `iota` и базовые типы

> ⏱ **~45 минут** · теория 15 мин · практика 30 мин

Базовый набор Go невелик, и это сознательно. Зато в нём есть две вещи, которых нет в большинстве языков: нулевые значения, избавляющие от неинициализированных переменных, и `iota` — компактный способ описывать наборы констант. Разберём и то, и другое.

## Объявление переменных

Два способа. Полная форма:

```go
var x int = 5
var y = 10        // тип выведен
var z int         // без значения
```

И короткая, доступная **только внутри функций**:

```go
y := 10
```

```go
// ❌ не компилируется
var pkg := 5
```

```
./bad2.go:3:9: syntax error: unexpected :=, expected =
```

На уровне пакета работает только `var`. Внутри функций почти всегда пишут `:=` — это идиома Go, полную форму оставляют для случаев, когда нужен явный тип или нулевое значение.

## Нулевые значения

Неинициализированных переменных в Go не бывает. Объявили без значения — получили **нулевое значение** типа:

```go
var a int
var b string
var c bool
var d float64
fmt.Printf("%d %q %t %g\n", a, b, c, d)
```

```
0 "" false 0
```

Числа — `0`, строки — пустая строка, `bool` — `false`, указатели и интерфейсы — `nil`.

Это не мелочь, а принцип проектирования. Разработчики Go старались, чтобы **нулевое значение было осмысленным**: у структуры `sync.Mutex` нулевое значение — готовый к работе незахваченный мьютекс, у `bytes.Buffer` — пустой буфер. Благодаря этому конструкторы в Go нужны реже, чем в других языках.

## Базовые типы

| Категория | Типы |
|---|---|
| Целые со знаком | `int8`, `int16`, `int32`, `int64`, `int` |
| Целые без знака | `uint8`, `uint16`, `uint32`, `uint64`, `uint`, `uintptr` |
| Дробные | `float32`, `float64` |
| Логический | `bool` |
| Строка | `string` |
| Комплексные | `complex64`, `complex128` |

Умолчания: `int` для целых, `float64` для дробных.

`int` — не отдельный размер, а псевдоним под разрядность платформы (на современных машинах 64 бита). Используйте именно его, если нет причин указывать точный размер: так код переносим и не требует преобразований при работе со стандартной библиотекой.

У `byte` и `rune` есть отдельные имена, но это псевдонимы: `byte` = `uint8`, `rune` = `int32`. Про них — в статье 8.

## Никаких неявных преобразований

Go не приводит числовые типы автоматически — даже когда это кажется безопасным:

```go
// ❌ не компилируется
var a int = 5
var b int64 = 10
_ = a + b
```

```
./bad.go:6:6: invalid operation: a + b (mismatched types int and int64)
```

`int` и `int64` — разные типы, даже если на вашей машине они одного размера. Преобразование пишется явно:

```go
_ = int64(a) + b
```

При этом преобразование может **потерять данные молча**:

```go
var f float64 = 3.9
fmt.Println(int(f))        // 3 — дробная часть отброшена

var big int64 = 300
fmt.Println(int32(big))    // 300, но при 3_000_000_000 было бы переполнение
```

Переполнение целых Go тоже не проверяет:

```go
var i8 int8 = 127
i8++
fmt.Println(i8)      // -128
```

Число обернулось. Ни ошибки, ни паники — такое поведение определено спецификацией. Отсюда правило: при работе с ограниченными типами проверяйте границы сами.

## Константы

```go
const Pi = 3.14159
```

Константы вычисляются на этапе компиляции и бывают только базовых типов — слайс или структуру константой не сделать.

Особенность, отличающая Go от большинства языков: константа может быть **нетипизированной**. `const Pi = 3.14159` не имеет типа до момента использования — и подставляется туда, где нужен и `float32`, и `float64`. Это избавляет от преобразований, которых требовали бы обычные переменные.

## `iota`

Для наборов связанных констант есть счётчик, обнуляющийся в каждом блоке `const`:

```go
type Weekday int

const (
	Sunday Weekday = iota    // 0
	Monday                   // 1
	Tuesday                  // 2
)
```

Значение и тип повторяются автоматически, писать `= 1`, `= 2` не нужно. Так в Go описывают перечисления — отдельного `enum` в языке нет.

Обратите внимание на `type Weekday int`: это **свой тип** на основе `int`, а не псевдоним. Функция, принимающая `Weekday`, не примет случайное число — дешёвая типобезопасность, к которой вернёмся в статье 10.

`iota` умеет участвовать в выражениях:

```go
const (
	_  = iota             // пропускаем 0
	KB = 1 << (10 * iota) // 1 << 10 = 1024
	MB                    // 1 << 20 = 1048576
)
```

```
1024 1048576
```

Выражение из второй строки повторяется для всех следующих, меняется только `iota`. Идиома для размеров, флагов и битовых масок.

Подчёркивание `_` — «пустой идентификатор»: значение вычисляется и выбрасывается. Именно им обходят запрет на неиспользуемые переменные из статьи 1.

## Форматный вывод

Пригодится с первого дня:

| Глагол | Что печатает |
|---|---|
| `%v` | значение в виде по умолчанию |
| `%+v` | то же, но у структур с именами полей |
| `%T` | тип значения |
| `%d`, `%s`, `%t`, `%g` | целое, строка, bool, дробное |
| `%q` | строка в кавычках |

```go
fmt.Printf("%v %T\n", y, y)     // 10 int
```

`fmt.Sprintf` возвращает строку вместо печати — аналог форматирования в других языках.

## Что запомнить

- Внутри функций объявляют через `:=`, на уровне пакета — только `var`.
- Неинициализированных переменных нет: есть нулевые значения, и язык спроектирован так, чтобы они были осмысленны.
- `int` — размер платформы; используйте его по умолчанию.
- Неявных числовых преобразований нет, даже между `int` и `int64`.
- Преобразование типов может молча потерять данные, а переполнение не проверяется.
- Константы вычисляются при компиляции; нетипизированная константа подстраивается под место использования.
- `iota` — счётчик внутри блока `const`, основной способ описывать перечисления.
- `_` — пустой идентификатор, обходит запрет на неиспользуемые значения.

## Практика

**1. Нулевые значения.** Объявите переменные всех базовых типов без инициализации и напечатайте их через `%q` и `%v`. Готово, когда можете назвать нулевое значение каждого типа не подглядывая.

**2. Преобразования.** Напишите программу, которая делит 7 на 2 как целые и как дробные числа. Затем преобразуйте `float64` со значением 2.99 в `int` и объясните результат. Готово, когда печатаются 3, 3.5 и 2.

**3. Переполнение.** Найдите максимальное значение `int8` (подсказка: пакет `math`), прибавьте единицу и объясните результат. Повторите для `uint8`. Готово, когда оба результата предсказаны заранее.

**4. Своё перечисление.** Опишите тип `Status` на основе `int` с константами `Pending`, `Active`, `Blocked` через `iota`. Напишите функцию, переводящую статус в строку. Готово, когда функция принимает только `Status`, а не любое число.

**5. Битовые размеры.** С помощью `iota` опишите константы `KB`, `MB`, `GB`, `TB`. Напечатайте их и проверьте по калькулятору. Готово, когда все четыре значения верны, а в коде нет ни одного явного числа кроме сдвига.
